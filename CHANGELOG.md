# @agentspaces/a2ui-react changelog

What changed in the open React renderer, newest first.

## Unreleased: 0.6.0

The first release of `@agentspaces/a2ui-react` on npm, from its own repository. It draws the catalogs of `agentspaces-a2ui` 0.6.0 over `@a2ui/react` and `@a2ui/web_core` 0.15.0.

- **The renderer (2026-11-10).** `Surfaces` draws a list of A2UI v0.9.1 envelopes over the basic catalog and every component of `agentspaces-viz`: Chart, DataTable, Map, Graph, Timeline, Report, Notification, Form, Stat, Window, Conversation, Notice, Toolbar, KeyValue and Prose. It hands each action a person takes to the page. `registerComponents` and `registerAlias` let a host add its own catalog, or let an old catalog id draw another catalog's components.
- **The frame of a page (2026-11-10).** `TitleBar` draws the app's name, icon, status and actions, and the first one on a page claims the page's one bar. `Menu` follows the WAI-ARIA Menu Button and Menu patterns, with groups, checked and disabled items, shortcuts, and one level of submenu. `Split` wraps the custom element `<agentspaces-split>`, the WAI-ARIA Window Splitter, with two or three panes, keyboard moves, collapse to a rail, and a stacking width. `Pages` draws a Publish's `navigation` as tabs or a rail, or its `layout` as whole surfaces in the panes of a split. `CommandPalette` offers every bar action and menu item on Ctrl or Cmd and K.
- **The application components (2026-11-10).** `Chat`, `FileTree` and `FilePreview` of `agentspaces-widgets` draw in the package. The chat shows the agent's progress and steps, says "The agent stopped" with Retry when a progress lapses, draws answers as safe Markdown whose code copies, and shows attachment and citation chips. The file tree wraps `<agentspaces-tree>`, the WAI-ARIA Tree View, with badges, upload, a context menu, and 2,000 rows drawn as a window. The preview draws text, Markdown, CSV, PNG, JPEG, and PDF in a frame with no permission, and draws HTML and SVG as their text. `ChatInput`, `Conversation` and `FileShare` draw through them as aliases through 0.6.x.
- **The look and the gallery (2026-11-10).** The look and feel is a set of CSS variables in `style.css`, and every chart follows one dataviz method for colour, marks, and light and dark mode. `Gallery` draws every golden surface of `agentspaces-a2ui` beside its code, and the build writes it as `dist/gallery.html`.
- **The checks (2026-11-10).** The build regenerates the catalog types, the registry and the golden surfaces from `agentspaces-a2ui` and fails when they differ. It also fails when a source file imports a closed module. Ninety tests cover the conformance of every golden surface, the keyboard patterns, view state, safe Markdown, the file preview, and the README's quick start. axe-core finds no serious or critical problem in the gallery in light or dark mode.
- **Fixes found in review (2026-11-10).** A submenu item now closes the top menu. Tab no longer leaves the command palette. Kept split sizes that are not shares are ignored, so a damaged browser store never draws a broken split.
- **The repository (2026-11-10).** The README follows the house shape, with a quick start that installs the package, bundles one page, and draws a title bar over a split. Beside it are `docs/`, the contributing guide, the security policy, the code of conduct, a `.gitignore`, and CI workflows that run the docs lint, the build and tests, the axe run, a dry run of the package, and an OSV dependency scan. `package.json` names the repository, the issues page, the author, and the files that ship, and publishes the scoped package as public.
